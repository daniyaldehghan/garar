# دفترچه خاطرات قرار 🌙
باز کردن: فایل `index.html` را با مرورگر باز کنید (نیازی به نصب چیزی نیست).

ساختار:
- `index.html` صفحه
- `css/style.css` استایل
- `js/utils.js` ابزارها (تاریخ شمسی، ستاره‌ها، قلب‌ها)
- `js/ui.js` ساخت ورودی/دکمه‌ها
- `js/steps.js` سؤال‌ها (اینجا سؤال جدید اضافه کنید)
- `js/main.js` جریان برنامه و نتیجه‌ی نهایی
